# Chicago Transitions

Runs the Chicago → Lakewood facility transition process: requests, tasks, reminders and emails, in one app.

- Open the app: see the GitHub Pages address in this repository's Settings → Pages.
- Try it without touching real data: add `?demo` to the address.
- Data lives in SharePoint (site in `config.js`). Emails go out from the shared mailbox through 2 Power Automate flows.
